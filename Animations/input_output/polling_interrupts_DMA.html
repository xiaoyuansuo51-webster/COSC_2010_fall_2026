Discussion: What changed: how the CPU learned the device was ready, or who moved the data?

Interrupts provide notification. DMA moves data. This example uses a completion interrupt for DMA; DMA completion can also be detected by polling.

Simplified teaching model: device readiness and transfer timing are identical across methods. CPU copies and DMA transfers each take one modeled tick per card. Real performance depends on hardware, interrupt overhead, polling frequency, and memory contention.
